# Optimization Intelligence Agent (Idea Log)

**Concept:** Build an agent system that continuously scrapes public data (news, filings, forums, tech blogs, hiring trends, etc.) to infer where specific companies are underperforming or ripe for optimization. Package the findings as actionable briefs we can sell directly to those companies ("here's where you're leaking margin / missing automation / customer signals, plus a suggested playbook").

**Initial thoughts:**
- Data sources: job postings (skill gaps), Glassdoor (employee pain), G2/Capterra reviews (product complaints), support forums, financial call transcripts.
- Output: prioritized issue list per company + estimated impact + suggested automation/agent solution.
- Business model: subscription intel feed for ops leaders / proactive outreach to offer custom build engagements.

**Status:** parked for later exploration.
